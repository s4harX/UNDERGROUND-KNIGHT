# Подземный рыцарь

Офлайн-игра в духе топ-даун роуглайк шутеров. Оригинальные спрайты, звуки и код не используются: графика рисуется на HTML Canvas, звук генерируется через Web Audio.

Версия **1.6**.

## Запуск

- **На компьютере:** открой `index.html` в любом современном браузере. Интернет не нужен.
- **На телефоне (PWA):** залей папку с игрой на любой HTTPS-хостинг (GitHub Pages, Netlify, Vercel — бесплатно), открой ссылку в браузере и выбери «Добавить на главный экран». После первой загрузки игра работает офлайн через service worker.
- Локально PWA можно проверить через `localhost`: `python -m http.server 8000` и открыть `http://localhost:8000`.

## Управление

### Клавиатура и мышь

| Клавиша | Действие |
| --- | --- |
| `WASD` / стрелки | Движение |
| Мышь | Прицел |
| ЛКМ | Стрельба |
| `Space` | Рывок с короткой неуязвимостью (разбивает ящики и бочки) |
| `R` | Перезарядка |
| `1`–`4` | Смена оружия |
| `E` | Открыть сундук / зайти в магазин / спуститься по лестнице |
| `P` / `Esc` | Пауза |
| `←` / `→` в меню | Выбор героя |
| `1`–`3` после зачистки | Выбор реликвии |
| `Enter` | Начать / перезапустить |
| Кнопка в правом верхнем углу меню | Достижения и задания |

### Телефон (горизонтальная ориентация)

- левая половина экрана — виртуальный джойстик;
- правая половина — прицел и удержание для стрельбы;
- кнопки справа — рывок `↠`, перезарядка `⟳`, смена оружия `⇄`, взаимодействие `E`, пауза `II`;
- в паузе есть кнопка **«Настройки»**: громкость, вибрация, тряска экрана и частицы;
- касание по карте реликвии — выбрать награду;
- касание по экрану в меню — начать игру, на паузе — продолжить.

## Что есть

- **3 этажа** с разными темами: Катакомбы, Ледяные пещеры, Огненные недра;
- на каждом этапе — процедурная карта из 16 комнат и свой босс: Страж, Ледяной сторож, Повелитель магмы;
- после победы над боссом открывается **лестница вниз**; на последнем этапе — победа;
- **3 героя** с разными характеристиками и стартовым оружием: Рыцарь, Разведчик, Танк;
- 8 типов врагов: обычный, стрелок, зарядчик, снайпер, бомбер, **щитоносец** (блокирует пули спереди, но уязвим для взрывов и удара сзади), **расщепитель** (при смерти распадается на двух малышей) и босс;
- **телеграфы атак** — лазерные линии и круги предупреждения перед выстрелами и рывками;
- **вторая фаза босса** с яростью и новыми паттернами; у каждого босса — свой набор атак;
- **арены** — комнаты с тремя волнами врагов; между волнами выпадают аптечки и патроны, за прохождение — улучшенная награда и достижение;
- **ловушки комнат** с шипами, ледяными шипами и метеоритами;
- **препятствия в комнатах**: деревянные ящики (разбиваются пулями и рывком), взрывающиеся бочки (цепочка взрывов, взрыв ломает соседние ящики) и каменные колонны (непробиваемые); пули проверяют столкновение по всей траектории, поэтому быстрые пушки не пролетают насквозь;
- 5 видов оружия, перезарядка и патроны;
- **реликвии с выбором 1 из 3** после зачистки комнаты;
- **критический урон** и всплывающие цифры урона;
- сундуки, монеты, аптечки, магазин и улучшения;
- мини-карта, уровни сложности, победа и поражение;
- **11 достижений** (первый убийца, 100 убийств, этажи 2 и 3, победа, 500 монет, 10 сундуков, комнаты без урона, 20 ящиков, 15 бочек, арена);
- **ежедневные задания** — 3 случайных цели в день с наградой 75 монет за каждую;
- экран «Достижения и задания» в меню с прогрессом и списком наград;
- сохранение рекордов, героя, достижений и заданий в `localStorage`;
- сид генерации в URL (`?seed=12345`) — можно кидать другу одинаковое подземелье; карты этажей тоже выводятся из сида;
- **процедурная музыка** и настройки звука/графики;
- PWA-манифест, иконки и офлайн-кэш;
- всё локально: без CDN, картинок и сетевых запросов.

## Файлы

- `index.html` — вся игра;
- `manifest.json` — настройки PWA;
- `sw.js` — service worker для офлайн-режима (кэш `v7`);
- `icon.svg`, `icon-192.png`, `icon-512.png` — иконки.
