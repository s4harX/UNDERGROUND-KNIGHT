# Подземный рыцарь

Офлайн-игра в духе топ-даун роуглайк шутеров. Оригинальные спрайты, звуки и код не используются: графика рисуется на HTML Canvas, звук генерируется через Web Audio.

Версия **1.21** — «Качество и полировка»: усилены визуал и читаемость — живой фон с глубиной, шлейфы пуль, светящиеся частицы, более выразительные всплывающие числа, пульсирующие подсказки взаимодействия, плавный затемняющий переход между ступенями с названием ступени, обновлённый титульный экран. Сохраняет v1.20: подсказки взаимодействия, тач-читаемость, вспышка урона, SFX портала/смерти/победы, враг **Страж-минёр**, оружие **Импульс**, баланс Угрозы/боссов. Наследие 1.19: 10 ступеней на главу, Угроза, засады, баффы каждые 3 ступени. Наследие 1.18: 16 новых видов оружия (всего 31), 16 баффов и 12 новых реликвий (всего 32), этажи в стиле Soul Knight. Наследие 1.17: медленная регенерация щита с задержкой, исчезающий журнал боя, исправленный тестовый режим и наёмники-спутники. Наследие 1.16: выбор слота для нового оружия, подсказки и тултипы, журнал боя, три уровня сложности, мини-карта с легендой, предпросмотр наград и магазина, тестовый режим. Наследие 1.15: новые враги и третья фаза боссов, настройки управления и тач-кнопок, отдельная громкость музыки и эффектов, reroll магазина, 4-й слот, стаки и banish реликвий, прогресс достижений, кнопки сида, FPS, пулинг и автотесты. Наследие 1.14: стабильность, баланс, миграции сохранений. Наследие 1.13: автонаведение, одна кнопка атаки/взаимодействия и полноэкранный режим.

## Запуск

- **На компьютере:** открой `index.html` в любом современном браузере. Интернет не нужен.
- **На телефоне (PWA):** залей папку с игрой на любой HTTPS-хостинг (GitHub Pages, Netlify, Vercel — бесплатно), открой ссылку в браузере и выбери «Добавить на главный экран». После первой загрузки игра работает офлайн через service worker. Пошаговая инструкция — в `DEPLOY.md`.
- Локально PWA можно проверить через `localhost`: `python -m http.server 8000` и открыть `http://localhost:8000`.
- Автотесты (без внешних зависимостей): `node tests/smoke.mjs`.

## Управление

### Клавиатура и мышь

| Клавиша | Действие |
| --- | --- |
| `WASD` / стрелки | Движение |
| Мышь | Прицел |
| ЛКМ | Стрельба |
| `Space` | Рывок с короткой неуязвимостью (разбивает ящики и бочки) |
| `Q` | Навык героя (у каждого свой) |
| `F` | Включить/выключить режим клинка (автоудар в упор, срубание пуль) |
| `R` | Перезарядка |
| `1`–`4` | Смена оружия; если все 4 слота заняты и найдено новое — выбор слота для замены |
| `M` | Развернуть карту этажа с легендой и стрелкой к боссу |
| `E` | Войти в портал следующей ступени / открыть сундук, клетку или трещину / зайти в магазин / спуститься по лестнице |
| `P` / `Esc` | Пауза; в окне выбора оружия — отказаться от нового оружия |
| `←` / `→` в меню | Выбор героя |
| `1`–`3` после зачистки | Выбор реликвии, `B` — исключить реликвию за 15 монет |
| `1`–`3` у портала | Выбор баффа (порталы после ступеней 3, 6 и 9) |
| `C` на экране конца | Скопировать сид забега |
| `Enter` | Открыть подготовку к забегу / продолжить |
| `H` в меню | Галерея героев и улучшений |
| `T` в меню | Экран испытаний |
| `1`–`5`, `N`, `B`, `V`, `C`, `H`, `6`–`8` в тестовом режиме | Глава, следующая ступень, босс, бафф, зачистка, лечение, монеты, самоцветы, уровень |
| `R`, `W`, `A`, `X` в тестовом режиме | Реликвия, оружие, засада, выход (также `Esc`) |
| `1`–`3` в испытаниях | Выбор режима |
| `F` / `O` / `G` / `S` / `V` в испытаниях | Модификаторы: скорость / перегрузка / туман / скудность / стекло |
| Верхний ряд кнопок в меню | Испытания / Герои / Достижения (и задания) / Установить игру |

### Телефон (горизонтальная ориентация)

- левая половина экрана — виртуальный джойстик;
- **одна кнопка `⊕` справа**: в бою — удержание для непрерывного огня по автоцели, рядом с порталом/лестницей/сундуком/торговцем/трещиной — нажатие для взаимодействия; ручного прицела нет, цель выбирает игра (приоритет настраивается: ближайший / опасный / слабый), зелёная рамка показывает захват;
- остальные кнопки — рывок `↠`, навык `Q`, клинок `⚔`, перезарядка `⟳`, смена оружия `⇄`, пауза `II`;
- **в паузе кнопки можно перетаскивать пальцем** — расположение сохраняется; размер кнопок и сброс раскладки — в настройках;
- **режим управления** (`авто` / `мышь` / `тач`) и приоритет автоцели переключаются в настройках;
- забег автоматически включает **полноэкранный режим** в Android Chrome; вернуть/выключить его можно в паузе → **«Настройки» → «На весь экран»** (на iOS полный экран работает у установленной PWA);
- в паузе есть **три страницы настроек**: громкость (общая / музыка / эффекты), вибрация, тряска, частицы, автонахождение, компактный HUD, цифры урона; вторая страница — управление, приоритет цели, FPS, размер кнопок, сброс раскладки, fullscreen; третья — сложность, журнал боя, подсказки, большая карта и тестовый режим;
- касание по карте реликвии или баффа — выбрать награду; при наведении курсора доступны подсказки по оружию, реликвиям, навыкам, щиту и товарам;
- **новое оружие никогда не заменяется само**: если все 4 слота заняты, игрок выбирает слот или оставляет текущее оружие;
- **щит восстанавливается медленно**: 4.5 с задержки после любого попадания, затем ~4–5 единиц в секунду (статуя стража ускоряет вдвое); подсказка на полоске щита показывает оставшееся время;
- **журнал боя** показывает только важные события и полностью исчезает через ~5.5 с, не загораживая поле боя;
- **сложность** (лёгкая / обычная / сложная) влияет на врагов и награды и применяется с нового забега;
- **наёмники**: в скрытом биоме (`ПОЛОЕ ДНО · СЕКРЕТ`) есть клетка — открой её, и наёмник присоединится, будет следовать за героем, стрелять по врагам и переходить с тобой между комнатами (до 3 наёмников);
- **тестовый режим** включается в настройках: вход — кнопка внизу меню или в паузе. Позволяет перейти на любой этаж, к боссу, зачистить комнату, выдать лечение, монеты, самоцветы, уровень, реликвию и оружие. Кнопка **«ВЫХОД»** (или `Esc`/`X`) возвращает в то же меню/паузу и полностью восстанавливает исходный забег и сохранение — рекорды, достижения и самоцветы из теста не сохраняются;
- касание по экрану в меню — начать игру, на паузе — продолжить;
- кнопка **«УСТАНОВИТЬ ИГРУ»** в меню вызывает системный диалог установки; если Chrome ещё не разрешил установку, открывается экран с инструкцией;
- экран на ПК увеличился до 1600 px, на телефоне canvas и шрифты подстраиваются под видимую область браузера.

## Что есть

- **5 глав** с разными темами: Катакомбы, Ледяные пещеры, Огненные недра, Заболоченные туннели и Бездна;
- каждая глава — извилистая цепочка из **10 ступеней** (`1-1 … 1-10`); сетка 5×5 используется только для мини-карты, а линия пути показывает порядок комнат; комната 10 — босс: Страж катакомб, Ледяной сторож, Повелитель магмы, Болотный тиран и Хранитель бездны;
- после зачищенной ступени открывается **портал**; после ступеней 3, 6 и 9 предлагается **1 из 3 баффов** (16 баффов забега, всего 15 выборов за забег);
- **Угроза** растёт с каждой главой и ступенью (от 1 до 13): враги получают больше здоровья, урона и скорости, чаще появляются элитные враги; урон при контакте ограничен, чтобы глубокие ступени оставались сложными, но не несправедливыми;
- **комнаты-засады**: сундук выглядит как обычный, но при нажатии `E` открывается засада — её отражение даёт дополнительные монеты и выбор реликвии;
- **боссы с тремя фазами**: ярость (55% HP), предельная ярость (25%) и уникальная финальная атака (10%) с кольцами снарядов, ловушками и призывом врагов; в босс-комнате 3+ главы может появиться **босс-близнец**;
- после победы над боссом открывается **лестница вниз**; после босса 5-й главы — победа;
- **режимы** (экран «Испытания»): обычный, **босс-раш** и **спринт** с рекордами;
- **модификаторы** — до двух за забег: быстрые враги, перегрузка атак, туман, скудный забег, стеклянный герой;
- **элитные враги**, **мини-боссы**, **тайные комнаты** и **наёмники** из клеток скрытого биома;
- **журнал боя** с автоисчезновением и подсказки по оружию, навыкам и реликвиям;
- **15 типов врагов**: обычный, стрелок, зарядчик, снайпер, бомбер, щитоносец (со ломаемым щитом), расщепитель, турель, лазерный стрелок, минер, фантом, **отражатель пуль**, **страж-минёр** (ставит опасные зоны), босс и босс-близнец;
- **6 героев** с активным навыком (`Q`);
- **31 вид оружия** (включая самонаводящиеся ракеты, спутники, яд, лечение при попадании, ударные волны и импульсный дробовик-отталкиватель), до 4 в слотах, **8 синергий**, слияние оружия (31 рецепт);
- **энергия выстрела**, **ближний бой**, **медленно восстанавливающийся щит**, критический урон;
- **6 статуй** после боссов 2-й и 4-й глав;
- **магазин**: 3 слота, 4-й покупается за 45 самоцветов, **reroll товаров** за монеты;
- **реликвии с выбором 1 из 3** — 32 реликвии четырёх редкостей, **стаки** уже полученных реликвий и **banish** за 15 монет;
- **27 достижений с полосками прогресса** и **ежедневные задания**;
- **экран конца забега**: меню, новый забег и кнопка сида для копирования/повтора;
- **настройки**: три страницы — громкость и эффекты; управление, тач-кнопки и fullscreen; сложность, журнал боя, подсказки, большая карта и тестовый режим;
- сохранение в `localStorage` с миграциями `schema`, сид генерации в URL (`?seed=12345`);
- **процедурная музыка**, PWA-манифест с отдельными maskable-иконками, офлайн-кэш `v23`;
- всё локально: без CDN, картинок и сетевых запросов.

## Файлы

- `index.html` — вся игра;
- `manifest.json` — настройки PWA;
- `sw.js` — service worker для офлайн-режима (кэш `v22`, навигация через сеть, остальные файлы — stale-while-revalidate);
- `icon.svg`, `icon-192.png`, `icon-512.png` — основные иконки;
- `icon-maskable-192.png`, `icon-maskable-512.png` — отдельные иконки для маски PWA;
- `tests/smoke.mjs` — автотесты без внешних зависимостей.
